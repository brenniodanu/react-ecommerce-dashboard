# 🛒 E-Store Modern Web Application

<div align="center">
  <p>Aplikasi E-Commerce modern berbasis React.js dengan tampilan Glassmorphism yang elegan, sistem autentikasi manual, integrasi Google OAuth, dan manajemen role (Admin & Customer).</p>
</div>

---

## ✨ Fitur Utama

- **🔐 Sistem Autentikasi Modern**: 
  - Login & Register Manual (Email & Password).
  - Integrasi **Google Login** menggunakan `@react-oauth/google`.
- **👑 Role-Based Access Control**: Pembagian hak akses otomatis antara **Admin** (Dashboard khusus) dan **Customer** (Halaman utama toko).
- **🎨 UI/UX Glassmorphism**: Desain antarmuka modern dengan efek transparan, animasi halus, dan *dark mode vibe*.
- **🔔 Custom Toast Notifications**: Notifikasi interaktif yang elegan menggantikan pop-up *alert()* bawaan browser.

---

## 🛠️ Teknologi yang Digunakan

* **Frontend:** React.js, React Router DOM
* **Styling:** CSS Modern (Flexbox, Glassmorphism, Keyframes Animations)
* **Authentication:** Google OAuth (`@react-oauth/google`)
* **API Client:** Axios
